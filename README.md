# ChessTool

Шахматный ассистент для chess.com: читает доску прямо с экрана, и подсказывает ходы
в стиле выбранного Elo (600–2500). Один файл, мгновенные ответы, невидимый оверлей.

## Что умеет

- **Авто-детект доски** на экране (темы chess.com: green/brown/blue/grey) + ручная
  калибровка рамкой (F2)
- **Распознавание позиции** по шаблонам фигур (инкрементально: ~10 мс на ход)
- **Stockfish 19 с Elo-капом** — на 1700 эло играет как человек 1700, не как 3300-й монстр
- **1–3 варианта хода** с подсветкой: откуда → куда, ранжированы цветом
- **Мгновенный ответ**: движок отвечает за 60–400 мс после хода противника
- **Human-delay**: подсказка показывается через случайные 0.3–1.4 с — время реакции
  не выглядит подозрительно маленьким
- **Stream-proof оверлей**: окно невидимо для OBS/скриншотов (WDA_EXCLUDEFROMCAPTURE),
  клики проходят сквозь него
- Ориентация доски определяется автоматически (игра белыми или чёрными)
- Тулка **не кликает за тебя** — ты ходишь сам, со стороны сайта это выглядит как
  обычный игрок, который думает над доской

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| F1 | старт / стоп анализа |
| F2 | калибровка доски рамкой |
| F3 | скрыть / показать оверлей |
| F4 | переключить 1 / 3 варианта хода |

## Установка (dev-запуск)

```
pip install -r requirements.txt
python main.py
```

Требуется `engines/stockfish.exe` (Stockfish 19, windows x86-64) — уже лежит в папке.

## Сборка exe (один файл)

```
build.bat
```

Pyinstaller соберёт `dist/ChessTool.exe` со встроенным движком и шаблонами.

## Как пользоваться

1. Открой игру на chess.com (крупная доска, стандартная тема фигур "neo")
2. Запусти ChessTool, выбери Elo — на этом уровне движок будет подсказывать
3. F1 — анализ начнётся, доска найдётся автоматически (или F2, выдели углы)
4. Противник сходил → через ~полсекунды увидишь подсветку: зелёная = лучший ход,
   жёлтая/оранжевая = альтернативы
5. Походи сам — подсветка очистится, ждём следующий ход противника

## Анти-детект дизайн

- Никаких кликов/инпута — только подсветка, ходы делаешь ты
- Elo-кап: ходы соответствуют заявленному уровню (никаких 98% accuracy на 1000 эло)
- Случайная задержка перед показом — человеческое время реакции
- На низких эло движок иногда выбирает 2-й/3-й ход — как живой человек, который зевает
- Оверлей исключён из захвата экрана — не попадает в OBS/скриншоты
- Наивысшая скрытность: F4 — только один ход, F3 — спрятать оверлей

## Структура

```
main.py              — вся программа (GUI, детектор, движок, оверлей)
engines/stockfish.exe — Stockfish 19
templates/*.png      — 12 шаблонов фигур chess.com (тема neo)
test_units.py        — офлайн-тесты (движок, распознавание, флип)
build.bat            — сборка exe
```
